# 通信矩阵

保留旧版非对比模式的热力图行为，由 lib 的 MIChart 负责生命周期、主题和尺寸更新。

- `index.tsx`：lib 筛选组件、局部条件和图表事件。
- `data.ts`：通信域 Rank、卡内通信/范围筛选、重复链路合并、指标与链路色带。
- `options.ts`：按通信域卡数计算图高（每行最大 50px，含坐标轴和色带的总高度最大 800px）、坐标轴、图内缩放、图例、悬停阴影和缩放后的标签显隐。
- `tooltip.ts` / `style.css`：旧版白底提示框，指标名和值分列、数值加粗、单位弱化；重复链路按指标合并。通过 DOM 文本节点显示接口内容。

普通滚轮和触控板双指滑动滚动页面；按住 Ctrl 滚动才缩放矩阵，放大后可拖动平移。重置缩放按钮同时恢复两轴全范围，保留指标和数值筛选。不显示横纵 dataZoom 拖动条。指标色带的范围拖动柄与旧版一样保留。新版不支持对比。
