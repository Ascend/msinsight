# MindStudio Insight Case Studies

This collection brings together typical application cases in scenarios such as memory analysis and performance tuning to help developers quickly master the core functions and usage of MindStudio Insight. By providing reproducible analysis paths and best practices, it helps users efficiently identify performance bottlenecks and resource anomalies during inference and training.

|Case|Scenario Description|
|-|-|
|[Locating Cluster Fast/Slow Rank Issues Based on MindStudio Insight](./Cluster_Slow_Rank_Analysis.md)|Following the path of "identifying performance differences between ranks in **Summary** -> locating waiting/synchronization anomalies in **Communication** -> comparing fast and slow ranks in **Timeline** -> determining that the slow rank is overloaded", this case describes how to locate cluster fast/slow rank issues with MindStudio Insight.|
|[Host Bound Issue Analysis Based on Linux Kernel Trace](./host_bound_analysis_with_linux_kernel_trace.md)|When analyzing Host Bound issues, Linux kernel ftrace data usually needs to be collected to observe process scheduling on the CPU. MindStudio Insight provides `ftrace_tools`, in which `trace_record.py` collects ftrace data, `trace_convert.py` converts the data format, and `trace_analyze.py` performs offline statistical analysis. These scripts support importing ftrace data and profiling data into the same project for joint analysis.|
|[JupyterLab Installation Guide](./Jupyter_Plugin_Installation_Guide.md)|For performance testing of large models, the collected profiling data is often very large or cannot be exported from the server, which makes analysis in a GUI difficult. MindStudio Insight provides a Jupyter-based plugin that requires no download of profiling data from the server and allows you to analyze the data locally in a web GUI through Jupyter.|
|[Analyzing Cube-Vector Fusion Operator Performance with MindStudio Insight](./Operator_Fusion_Analysis.md)|Taking the official Ascend C example [MatmulLeakyRelu fusion operator](https://gitcode.com/cann/asc-devkit/tree/9.2.0/examples/01_simd_cpp_api/00_introduction/03_fusion_operation) as an example, this case describes how to use MindStudio Insight to analyze the performance of Cube-Vector fusion operators.|
|[Analyzing Memory Issues Based on PyTorch Snapshot Data](./pytorch_snapshot_memory_analysis.md)|By importing PyTorch Snapshot data into MindStudio Insight, you can use memory block lifecycles, memory pool states, and call stacks to precisely identify memory leaks, memory usage peaks, and memory fragmentation in multi-stage training scenarios such as reinforcement learning.|
|[Case Study on Analyzing Memory Issues Based on PyTorch Snapshot Data](./profiler_memory_example.md)|In complex training scenarios such as reinforcement learning, the overall memory curve alone cannot distinguish memory leaks, transient peaks, or fragmentation issues. By importing PyTorch Snapshot data into MindStudio Insight, this case describes how to use the memory block timeline graph, memory pool state diagram, and call stack information to precisely locate the stage, source, and fragmentation of memory anomalies.|
|[Locating ResNet50 Training Memory Leaks Based on PyTorch Snapshot](./pytorch_snapshot_memory_leak_optimization.md)|By building a ResNet50 training scenario, this case demonstrates a typical problem in which storing a Device Tensor directly in a history list prevents the release of Python references, causing memory leaks and even OOM, and provides the fix. Combined with PyTorch Snapshot analysis and long-cycle training verification, the document proves that recording only Host scalar values can effectively avoid such memory leaks.|
|[Single-Rank Top-Down Operator Dispatch Bottleneck Analysis](./Single_Card_Top_Down_Dispatch_Analysis.md)|Taking dispatch bottlenecks as an example, this case describes how to start from the overall proportion in Overlap Analysis and gradually locate the operator dispatch path and possible host-side root causes.|
|[Snapshot Data Collection and Analysis Case in verl](./verl_Memory_Snapshot_Collection_and_Analysis.md)|This case describes how to use the built-in `torch_memory` of the verl framework to collect memory snapshots of training stages such as PPO, so as to locate peak sources, monitor memory leaks, and compare differences between ranks. It also provides a concrete case of visualizing and analyzing the collected data with MindStudio Insight.|
|[Timeline Unit Overview](./Timeline_Common_Lanes_and_Interface.md)|1. What are the common units and GUI elements of the Timeline? How do they relate to each other?<br>2. What is Overlap Analysis?<br>3. What issues is the Timeline commonly used to observe?|
|[Keyboard Shortcuts](./Keyboard_Shortcuts.md)|MindStudio Insight is committed to providing users with a smoother and more efficient operating experience. To help you get started with these efficient tools more quickly, this document introduces some commonly used keyboard shortcuts.|
